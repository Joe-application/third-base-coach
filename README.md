# 三塁コーチャー判断トレーナー

少年野球（学童軟式・小5〜6）の三塁コーチャーが「回す／止める」を練習する Web アプリ。
仕様書：`~/Downloads/third-base-coach-spec.md`

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173/
npm test         # シミュレーションのユニットテスト＋キャリブレーションテスト
npm run build    # dist/ に静的サイト（base: './' なので GitHub Pages のサブパスでも動く）
```

## 構成

- `src/sim/` … UI に依存しない純粋関数のシミュレーション。数値はすべて `constants.ts`
  - `simulatePlay(scenario, commands, draws)` → `PlayTimeline`（フレーム列・イベント・結果）
  - `evaluate.ts` … モンテカルロで P_safe、採点、タイミング判定
  - `draws.ts` … 1プレーの乱数を先に全部引いておき、判断時点で確定した事象だけ固定して引き直す
- `src/game/` … ランク・★・コンボ・バッジ（`progression.ts`）、localStorage（`storage.ts`）、
  子ども向けの文言（`messages.ts`。`{漢字|よみ}` でふりがな）
- `src/ui/` … 画面（ホーム・入門・プレー・結果・まとめ・自由練習・記録・設定）と SVG のグラウンド

## 仕様から変えた数値（キャリブレーション）

仕様どおりの数値だと守備が速すぎて、「あの日の場面（2アウト）」の P_safe が 0.25 になった。
学童らしい守備の遅さ・不確実さを入れて、目標範囲に合わせた。`constants.ts` の【調整】コメント参照。

| 定数 | 仕様 | 変更後 | 理由 |
|---|---|---|---|
| 持ち替え時間 前進/横/後ろ | 0.8–1.0 / 1.1–1.4 / 1.5–2.0 | 0.55–0.75 / 0.7–0.9 / 0.9–1.2 | 実際の持ち替えは速い（一度長くしたが、2回短くした） |
| 中継の持ち替え | 0.8–1.2 | 0.4–0.6 | 同上 |
| 肩 弱い/普通/強い の送球の速さ・届く距離 | 18・45 / 21・55 / 24・65 | 16・41 / 19・50 / 22・59 | 持ち替えを短くしたぶん、小6の外野手らしい送球に（普通 = 約 68km/h） |
| 二次リード | （なし） | 2m | 打った瞬間、二塁から 3m + 2m の位置にいる |
| 走者の反応 / 0・1アウトのゴロの待ち | 0.2 / +0.5 秒 | 0.1 / +0.35 秒 | 実際のスタートはもっと早い |
| 遠い送球の速度低下（d_max で） | 0.65×v | 0.55×v | 山なり送球をもう少し遅く |
| 送球の速さのばらつき | なし | 標準偏差 16% | 学童の送球はばらつく |
| タッチ時間 / 捕手が動く時間 | 0.4 / 0.4 | 0.5 / 0.5 | |
| クロスプレーのロジスティック幅 / 確定マージン | 0.15 / ±0.6 | 0.30 / ±1.08 | タッチプレーの不確実さ。境目で確率が飛ばない値 |
| ゴロの減速度 内野/外野 | 3.0 / 4.0 | 3.5 / 4.5 | |
| 最初のバウンドまで | （なし） | 6m | 打球直後は減速しない区間 |
| ワンバウンド送球の判定 | （なし） | 距離 > 0.8×d_max | 捕手の捕球ミス 15% の条件 |

キャリブレーション結果（2000回）：

| シナリオ | 目標 | 結果 |
|---|---|---|
| あの日の場面（2アウト） | 0.55–0.70 | 0.64 |
| あの日の場面（0アウト） | 0.45–0.65 | 0.51 |
| レフト正面の強いゴロ・前進守備・肩強い・0アウト | 0.10–0.30 | 0.13 |
| 右中間を破る打球・2アウト | ≥0.90 | 1.00 |
| センター前の弱いゴロ・1アウト | 0.50–0.70 | 0.54 |

二塁→本塁の所要時間は、仕様の条件（リード 3m・反応 0.2 秒）では 8.1 秒で、仕様の 7.8〜8.6 秒に入る。
二次リードと早いスタートを入れた実際のプレーでは、2アウトで約 7.7 秒。

## 判断のタイミング

試合は待ってくれないので、プレーは止まらない（見習いのヒントも止めずに上のバーに出す）。
- 締め切り：判断する塁（三塁、打者走者は二塁）の手前 3m。過ぎたら「おそい」で ×、ランナーは迷って止まる
- はやすぎ：判断ウィンドウ（塁の手前 12m）の前、かつ外野手が捕る 0.3 秒より前に合図すると ×
- 判断できる間はボタンが光り、フィールドの下に残り時間のバーが出る

## チャレンジ10問の中身

- 外野手の前に落ちる単打 7問：レフト線・レフト前・左中間前・センター前・右中間前・ライト前・ライト線 を1問ずつ
- ランナー一塁の長打 2問：一塁走者が二塁を回って三塁へ。三塁で止めるか、本塁へ回すか
- 外野の間を抜ける長打 1問：二塁走者を回したあと、打者走者の判断も出る

## 打者走者の判断（二塁を回るか）

外野の間を抜ける・頭を越える長打（外野手が後ろ向きで追う、フェンスまで転がる、本塁から 60m 以上で捕る）で
二塁走者を回すと、二塁に近づく打者走者にも「二塁ストップ／三塁へ！」の合図を出す。`src/sim/batter.ts`

- 守備：二塁走者が本塁で楽にセーフ（送球より 0.3 秒以上早い）なら、中継は本塁ではなく三塁へ投げる。
  そうでなければ本塁へ投げ、本塁のプレーのあと捕手が三塁へ投げる
- 基準（三塁セーフ確率）：0アウト 70% ／ 1アウト 65% ／ 2アウト 85%（「三塁でアウトになるな」）
- 点数：◎50 ○30 ×0、タイミング +10／迷い −15、三塁セーフ +10（1プレーの中の2つ目の判断なので半分くらい）
- 目安：右中間を深々と破る打球（1アウト・バッターの足がはやい）は約 0.82、右中間を抜けるだけの打球は約 0.14

## 声

「回れー！回れー！」「セーフ！」などの声は `public/voice/*.m4a`。Higgsfield（Seed Audio 1.0、日本語男性プリセット「太郎」、
高さ +4・速さ +5・大きさ +30）で作り、前後の無音と途中の長い間を削ってモノラル AAC 64kbps にした。
セリフは `src/game/messages.ts` の `VOICE` と同じ。音声ファイルが読めない端末では、同じ文を端末の読み上げでしゃべる。
